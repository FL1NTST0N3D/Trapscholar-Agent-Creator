Get started

Installation

Five steps from repository to a running skill inside Claude.

1

Download or clone the repository

Get the full skill folder onto your machine.

2

Keep SKILL.md at the root

Claude reads this file to load the skill's instructions.

3

Package the folder as a ZIP

Only if your Claude interface requires a ZIP upload.

4

Open Settings → Customize → Skills

This is where skills get uploaded and enabled in Claude.

5

Upload and enable it

The skill is now active for your conversations.

git clone https://github.com/zakaryabelleboukh/amazon-kdp-skill.git cd amazon-kdp-skill

Prompts you can copy

Hand these to Claude once the skill is enabled.

Create a book
I want to create a children's activity book for ages 6–8.
Build the complete book concept, page structure, activity plan,
writing guidelines, cover brief, metadata and publishing checklist.
Improve a manuscript
Review this manuscript as a professional editor.
Improve clarity, structure, consistency and reader experience.
Do not change factual claims unless they are clearly identified
for verification.
Prepare metadata
Create a complete KDP metadata package for this book:
title, subtitle, description, seven keyword ideas, category
suggestions, audience and publishing checklist. Keep every claim
accurate to the actual manuscript.
Final QA
Run a complete pre-publication KDP QA audit. Check manuscript
structure, front matter, back matter, TOC, formatting consistency,
metadata consistency, cover requirements and anything that could
cause publishing problems.
