# Contributing

Thanks for helping improve Amazon KDP Publishing Expert.

## Guidelines

- Keep the skill focused on professional book-production workflows.
- Do not add fabricated Amazon policies, statistics, market data or guarantees.
- Prefer official KDP documentation for current platform requirements.
- Keep instructions clear, deterministic and useful for Claude.
- Avoid copyrighted text samples unless they are legally appropriate.
- Explain breaking changes in `CHANGELOG.md`.

## Pull requests

Please describe:
- what changed
- why it changed
- how it improves the skill
- any new workflow or prompt examples
- any limitations or assumptions
