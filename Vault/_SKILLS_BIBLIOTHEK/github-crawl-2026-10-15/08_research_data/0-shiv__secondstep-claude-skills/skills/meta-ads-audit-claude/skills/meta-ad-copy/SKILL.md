# Meta Ad Copy Audit

## Command
`/meta copy`

## Description
Analyzes ad copy quality across all active Meta ads, including primary text effectiveness, headline scoring, description utilization, CTA button selection, emoji and formatting usage, and platform-specific copy optimization for Feed, Stories, and Reels. Strong ad copy can improve CTR by 30-50% without any media changes.

## Why Ad Copy Quality Matters

Meta ads have three text fields, each serving a different purpose in the user's decision journey:

- **Primary Text**: The main body copy shown above the creative. First 125 characters visible before "See More" — this is your hook.
- **Headline**: Bold text below the creative (Feed) or overlaid on creative (Stories). Maximum impact zone.
- **Description**: Supporting text below the headline (Feed only). Often truncated or hidden.

Studies show that **62% of Meta ad performance variation** comes from creative and copy, while only 38% comes from targeting and bidding. Yet most advertisers spend 90% of their time on targeting.

## Audit Checklist (25 Points)

### 1. Primary Text Analysis (7 points)

- [ ] **Hook in First Line**: First 125 characters (before "See More") contain a compelling hook
  - Problem/pain point hook
  - Curiosity hook
  - Social proof hook (numbers, testimonials)
  - Direct benefit hook
- [ ] **Length Optimization**: Test both short (1-2 lines) and long (3-5 paragraphs) primary text
- [ ] **Value Proposition Clear**: Reader understands what is offered and why within 3 seconds
- [ ] **Social Proof Present**: Numbers, reviews, testimonials, or authority signals included
- [ ] **Urgency/Scarcity**: Where appropriate, time-limited offers or scarcity elements used
- [ ] **Single CTA Focus**: Copy drives toward one clear action (not multiple competing asks)
- [ ] **Mobile Readability**: Short paragraphs, line breaks, scannable format (80%+ of Meta traffic is mobile)

**Primary Text Hook Frameworks:**
| Framework | Example |
|-----------|---------|
| Problem-Agitate-Solve | "Tired of wasting ad budget? 73% of advertisers..." |
| Social Proof Lead | "12,847 marketers already switched to..." |
| Curiosity Gap | "The one targeting mistake costing you 30% of ROAS..." |
| Direct Benefit | "Get 3X more leads without increasing your ad spend" |
| Question Hook | "What if you could cut your CPA in half this month?" |
| Contrarian | "Stop optimizing for conversions. Here's why..." |

### 2. Headline Scoring (5 points)

Headlines appear in the most prominent position (bold, below or on the creative).

- [ ] **Character Count**: Headlines under 40 characters for full visibility across placements
- [ ] **Action-Oriented**: Headlines contain verbs and drive action ("Shop Now" not "Our Collection")
- [ ] **Benefit-Focused**: Headlines communicate the outcome, not just the feature
- [ ] **Headline Variations**: Testing at least 3 different headlines per ad or in dynamic creative
- [ ] **Headline-Creative Alignment**: Headline reinforces the message in the creative image/video

**Headline Scoring Rubric:**
| Score | Criteria |
|-------|----------|
| 5/5 | Action verb + specific benefit + under 40 chars |
| 4/5 | Clear benefit + appropriate length |
| 3/5 | Generic but relevant headline |
| 2/5 | Vague or too long (truncated on mobile) |
| 1/5 | Missing, irrelevant, or misleading |

### 3. Description Usage (3 points)

Descriptions are often overlooked but provide additional context in Feed placements.

- [ ] **Description Present**: All Feed ads have descriptions filled in (not left blank)
- [ ] **Supporting Information**: Descriptions add new information (not repeat headline)
- [ ] **Social Proof or Urgency**: Descriptions used for secondary trust/urgency signals

### 4. CTA Button Selection (4 points)

Meta offers predefined CTA buttons. The right CTA aligns with the campaign objective and user intent.

| CTA Button | Best For |
|-----------|----------|
| Shop Now | E-commerce product purchases |
| Learn More | Information-seeking, top-of-funnel |
| Sign Up | Newsletter, course, free trial |
| Book Now | Appointments, reservations, consultations |
| Get Offer | Promotions, discounts, deals |
| Download | Apps, guides, resources |
| Contact Us | Service-based businesses, B2B |
| Apply Now | Jobs, financial products, applications |
| Get Quote | Insurance, custom services |
| Subscribe | Subscriptions, SaaS, memberships |

- [ ] **CTA Relevance**: CTA button matches the landing page action
- [ ] **CTA Consistency**: CTA in copy aligns with CTA button (don't say "Learn More" in copy with "Shop Now" button)
- [ ] **CTA Testing**: Are different CTAs being tested? (CTA changes can shift CTR by 10-20%)
- [ ] **CTA by Funnel Stage**: Appropriate CTA intensity for funnel position (Learn More for TOF, Shop Now for BOF)

### 5. Emoji & Formatting Usage (3 points)

- [ ] **Emoji Strategy**: Emojis used purposefully (bullet points, attention, emotion) not randomly
- [ ] **Emoji Placement**: Lead emojis at line starts for scanability, not mid-sentence
- [ ] **Line Breaks**: Copy uses line breaks for readability (especially mobile)

**Emoji Best Practices:**
- Use as bullet points: checkmarks, arrows, stars
- Use for emotion: relevant emotional emojis that match the tone
- Limit to 3-5 per ad (more = spammy)
- Never use emojis that could be misinterpreted or culturally insensitive
- Test emoji vs no-emoji variations

### 6. Platform-Specific Copy (3 points)

Different placements require different copy approaches:

| Placement | Primary Text | Headline | Style |
|-----------|-------------|----------|-------|
| Feed | Full length, "See More" truncation | Below creative, prominent | Professional, detailed |
| Stories | Short, overlay-friendly | Overlaid on creative | Casual, direct |
| Reels | Minimal, video does the talking | Short, punchy | Trend-aware, casual |
| Right Column | Barely visible | Most important element | Ultra-concise |
| Audience Network | May not display | May not display | Focus on creative |

- [ ] **Placement-Aware Copy**: Are different text variations used for Feed vs Stories vs Reels?
- [ ] **Stories/Reels Copy Length**: Copy for vertical placements is short (< 75 characters)
- [ ] **Feed Copy Optimization**: Feed-specific copy leverages full "See More" expansion

## Copy Quality Scoring

Each ad receives a copy quality score based on:

| Dimension | Weight | Scoring |
|-----------|--------|---------|
| Hook strength | 25% | 1-5 scale |
| Value proposition clarity | 20% | 1-5 scale |
| Headline effectiveness | 20% | 1-5 scale |
| CTA alignment | 15% | 1-5 scale |
| Formatting & readability | 10% | 1-5 scale |
| Platform optimization | 10% | 1-5 scale |

## Common Issues & Fixes

### Issue: All Ads Have Same Copy
**Symptom**: 5 ads running with identical primary text, headline, and description
**Root Cause**: Copy testing not implemented
**Fix**: Create 3-5 copy variations per ad set. Test different hooks, lengths, and angles.

### Issue: Copy Too Long for Mobile
**Symptom**: Primary text is 500+ characters with no line breaks, truncated to "See More"
**Root Cause**: Copy written for desktop reading experience
**Fix**: Front-load the hook in first 125 characters. Use short paragraphs and line breaks.

### Issue: Generic CTAs Everywhere
**Symptom**: Every ad uses "Learn More" regardless of objective
**Root Cause**: Default CTA not customized
**Fix**: Match CTA to landing page action. E-commerce = "Shop Now", Lead gen = "Sign Up" or "Get Quote".

### Issue: No Social Proof in Copy
**Symptom**: Copy describes features but includes no validation or trust signals
**Root Cause**: Social proof not collected or not prioritized in copywriting
**Fix**: Add customer count, rating, testimonial snippet, or authority mention to copy.
