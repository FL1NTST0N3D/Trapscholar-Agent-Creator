# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-03-15

### Added
- Main `/schema` skill with 12 commands
- 11 dedicated sub-skills: Organization, LocalBusiness, Product, FAQPage, HowTo, Article, VideoObject, BreadcrumbList, Event, Validator, Report
- 12 JSON-LD templates (organization, local-business, product, faq, howto, article, video, breadcrumb, event, service, review, speakable)
- 3 Python utility scripts (generator, validator, report crawler)
- 3 agent definitions (schema-audit, schema-migration, schema-deployment)
- Google rich result eligibility validation
- Multi-schema `@graph` support for pages needing multiple types
- Platform deployment guidance (WordPress, Shopify, Next.js, GTM, static HTML)
- 2023-2024 FAQ/HowTo restriction awareness
- install.sh and uninstall.sh scripts
- Full documentation (README, SKILL.md, CLAUDE.md, CONTRIBUTING.md)
