# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-03-15

### Added
- Initial release with 10 script categories
- Budget management scripts (pacing, monthly limiter, pause at threshold, shared budget monitor)
- Bid management scripts (hourly, device, geo, ROAS-based)
- Reporting scripts (daily email, weekly Sheets, MCC cross-account, custom KPI dashboard)
- Link checker scripts (ad URLs, sitelinks, keyword URLs, broken links report)
- Quality Score tracking scripts (daily logger, drop alerts, trends, component tracker)
- Search term scripts (high-performer mining, negative flagger, N-gram analysis, cost analysis)
- Anomaly detection scripts (spend, CPA, CTR, conversion volume)
- Labeling scripts (performance tier, budget tier, conversion, dynamic refresh)
- Script generator (plain English to script, template customizer, combiner, error handler wrapper)
- Script audit tools (inventory, execution history, error log analyzer, optimization recommendations)
- 3 Claude Code agents: script-builder, script-debugger, script-optimizer
- 8 JavaScript template files for common automation patterns
- Python utilities: script validator and template renderer
- Documentation: API reference, execution limits, troubleshooting, best practices
- install.sh and uninstall.sh for one-command setup
