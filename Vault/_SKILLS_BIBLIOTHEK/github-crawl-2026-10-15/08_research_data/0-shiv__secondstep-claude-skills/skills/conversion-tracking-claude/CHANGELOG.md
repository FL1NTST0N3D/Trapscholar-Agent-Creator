# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-03-15

### Added
- Main skill orchestrator with `/track audit` command routing
- 10 sub-skills: Google Tag, Enhanced Conversions, Server-Side GTM, Offline Import, Meta Pixel, Meta CAPI, LinkedIn Insight, TikTok Pixel, Attribution, Report
- 4 specialized agents: audit orchestrator, tag inspector, data quality, report generator
- Python validation scripts: tag validator, EC checker, pixel auditor, report generator
- Tracking Health Score (0-100) with scoring rubric
- Cross-platform validation framework (Google, Meta, LinkedIn, TikTok)
- Audit report and tracking checklist templates
- Install and uninstall scripts
- Full documentation suite
