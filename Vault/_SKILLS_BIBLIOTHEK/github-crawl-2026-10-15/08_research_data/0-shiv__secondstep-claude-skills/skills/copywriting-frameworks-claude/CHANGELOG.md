# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-03-15

### Added
- 12 copywriting framework skills: AIDA, PAS, FAB, BAB, 4Cs, Storytelling (StoryBrand/PASTOR/QUEST/PPPP/Star-Chain-Hook/SSS), Power Words, Headlines, CTA Formulas, Objection Handling, Social Proof, Copy Report
- 3 specialized agents: Copy Strategist, Copy Reviewer, Copy A/B Tester
- Master SKILL.md with framework selection guide by channel, objective, and audience temperature
- Copy router skill (`copy/SKILL.md`) mapping `/copy` subcommands to framework skills
- Tone modifier support: `--formal`, `--casual`, `--urgent`, `--luxury`, `--technical`, `--playful`, `--empathetic`, `--bold`
- 4 output formats: raw copy, structured, variations, channel-specific
- Python utility scripts: `copy_generator.py`, `copy_analyzer.py`
- Documentation: framework cheatsheet, industry examples, testing guide, prompt engineering guide
- `install.sh` automated installer and `uninstall.sh` uninstaller
