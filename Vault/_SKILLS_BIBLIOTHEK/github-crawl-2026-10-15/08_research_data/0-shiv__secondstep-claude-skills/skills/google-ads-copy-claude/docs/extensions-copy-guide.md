# Ad Extensions Copy Guide

## Why Extensions Matter for Copy

Extensions increase ad real estate by 15-25%, boost CTR by 10-20%, and improve Ad Rank. They're essentially free extra ad copy space.

## Sitelink Extensions

### Character Limits
- **Title**: 25 characters
- **Description Line 1**: 35 characters
- **Description Line 2**: 35 characters

### Writing Sitelink Titles (25 chars)
- Use as secondary CTAs or category navigation
- Include keywords where natural
- Each sitelink should point to a DIFFERENT page

**Examples by Industry:**

| Industry | Sitelink Titles |
|----------|----------------|
| E-commerce | "Shop New Arrivals" / "Sale — Up to 50% Off" / "Free Shipping Info" / "Customer Reviews" |
| SaaS | "See Pricing Plans" / "Start Free Trial" / "Watch Demo Video" / "Read Case Studies" |
| Local Services | "Our Services" / "Get a Free Quote" / "See Our Reviews" / "Service Areas" |
| Healthcare | "Book Appointment" / "Meet Our Doctors" / "Insurance Accepted" / "Patient Resources" |

### Writing Sitelink Descriptions (35 chars x 2 lines)
- Expand on the title with a benefit or detail
- Line 1: Feature or benefit
- Line 2: CTA or qualifier

**Example:**
```
Title: "Free Shipping Info" (18 chars)
Line 1: "Free standard shipping over $50." (32 chars)
Line 2: "Express options available too." (29 chars)
```

## Callout Extensions

### Character Limit: 25 characters each

Callouts are short, non-clickable highlights. Use them to showcase USPs that don't fit in headlines.

**Best Practice:** Use 8-10 callouts. Google shows 2-6 per impression.

**Universal Callout Examples:**
- "Free Shipping" (13)
- "24/7 Customer Support" (21)
- "No Hidden Fees" (14)
- "Money-Back Guarantee" (20)
- "Licensed & Insured" (18)
- "Family-Owned Since 2005" (23)
- "Same-Day Service" (16)
- "Price Match Guarantee" (21)
- "Flexible Payment Plans" (22)
- "Award-Winning Service" (21)

**Rules:**
- Don't repeat what's in your headlines or descriptions
- Don't use excessive punctuation
- Don't include CTAs (callouts aren't clickable)
- Use sentence case, not ALL CAPS

## Structured Snippet Extensions

### Character Limit: 25 characters per value

Structured snippets showcase specific aspects of your products/services under a header.

**Available Headers:**
- Amenities
- Brands
- Courses
- Degree programs
- Destinations
- Featured hotels
- Insurance coverage
- Models
- Neighborhoods
- Service catalog
- Shows
- Styles
- Types

**Examples:**
```
Header: Types
Values: "Emergency Plumbing" | "Drain Cleaning" | "Water Heater Repair" | "Pipe Replacement"

Header: Brands
Values: "Nike" | "Adidas" | "Puma" | "New Balance" | "Reebok"

Header: Amenities
Values: "Free WiFi" | "Pool" | "Fitness Center" | "Room Service" | "Spa"
```

## Promotion Extensions

### Character Limits
- **Occasion**: Selected from list (New Year's Sale, Back to School, etc.)
- **Promotion type**: Monetary or percentage discount
- **Item**: 20 characters
- **Promotion details**: "Orders over" / "Promo code"

**Writing Tips:**
- Keep the item description concise ("All Shoes" not "All of Our Amazing Shoes")
- Match the promotion to the occasion when possible
- Set accurate start/end dates
- Ensure the promotion matches what's on the landing page

## Price Extensions

### Character Limits
- **Header**: 25 characters
- **Description**: 25 characters
- **Price**: Automatically formatted

**Writing Tips:**
- Use the header for the product/service name
- Use the description for a key differentiator
- Show your most compelling prices
- List 3-8 price items for visibility

**Example:**
```
Header: "Basic Plan" (10 chars)
Description: "For small teams" (15 chars)
Price: $29/mo

Header: "Pro Plan" (8 chars)
Description: "Advanced analytics" (18 chars)
Price: $79/mo
```

## Image Extensions

While not copy per se, image extensions complement your text:
- Use images that match your ad copy messaging
- If headline says "New Collection," show new collection imagery
- If headline says "Before & After," show transformation images
- Images should be high-quality, relevant, and policy-compliant

## Extension Strategy

### Minimum Extension Set (Every Campaign):
1. 4+ sitelinks with descriptions
2. 8+ callouts
3. 2+ structured snippet headers
4. Location extension (if applicable)
5. Call extension (if phone leads are a goal)

### Advanced Extension Set:
- Promotion extension (when running offers)
- Price extension (when pricing is competitive)
- Image extension (all campaigns)
- Lead form extension (for lead gen campaigns)

### Extension-to-Ad-Copy Alignment:
- Extensions should COMPLEMENT ad copy, not repeat it
- If your headline says "Free Shipping," don't make a callout that also says "Free Shipping"
- Use extensions to cover USPs that didn't fit in the main ad
- Think of extensions as your "supporting cast" — the ad copy is the lead
