# Description Writer — Conversion-Optimized Ad Descriptions

## Command: `/copy descriptions`

Generate high-converting Google Ads descriptions (90 characters max) using proven copywriting structures, USP integration, and strategic CTA placement.

## Required Inputs

- **Business/Product**: What is being advertised
- **Primary Keyword**: Search term this ad targets
- **USPs** (list 3-5): Price, speed, quality, guarantee, selection, expertise, technology
- **Offer**: Current promotion, discount, free trial, etc.
- **CTA preference**: What action do you want? (Call, visit, buy, sign up, get quote)
- **Tone**: Professional, friendly, authoritative, casual, urgent

## Description Anatomy

Every high-performing description follows this structure:

```
[Hook/Problem] + [Solution/USP] + [CTA with benefit]
```

The 90-character limit forces ruthless prioritization. Every word must earn its place.

### The Three Zones of a Description

**Zone 1 — The Hook (first 30 chars)**
This is the only part guaranteed to show on mobile. Lead with the most compelling element.
- Pain point: "Tired of slow loading sites?"
- Benefit: "Cut your tax bill by 40%."
- Social proof: "Rated #1 by Consumer Reports."
- Offer: "Save 30% this month only."

**Zone 2 — The Value Prop (middle 30 chars)**
Expand on why you're different. Add a feature, benefit, or proof point.
- Feature + Benefit: "AI-powered analytics reveal hidden revenue."
- Trust signal: "Licensed, bonded & insured."
- Differentiator: "Same-day delivery included."

**Zone 3 — The CTA (final 30 chars)**
Close with a clear, specific action. Generic CTAs like "Learn More" underperform specific ones.
- Specific: "Get your free roof inspection today."
- Urgent: "Book now — spots filling fast."
- Low-commitment: "See pricing — no credit card needed."

## Description Formulas

### Formula 1: Problem + Solution + CTA (PAS Framework)
```
Tired of [pain point]? [Your solution] [key benefit]. [CTA] today.
```
Example: "Tired of unreliable WiFi? Our mesh system covers every room. Get free install today." (84 chars)

### Formula 2: USP + Proof + CTA (FAB Framework)
```
[Unique feature] means [benefit]. [Proof point]. [CTA].
```
Example: "Military-grade encryption keeps data safe. Trusted by 5,000+ firms. Start free trial." (87 chars)

### Formula 3: Offer + Urgency + CTA (Urgency Framework)
```
[Offer detail] — [urgency qualifier]. [CTA with benefit].
```
Example: "Save 40% on all plans this week only. No contracts, cancel anytime. Claim your discount." (89 chars)

### Formula 4: Social Proof + Benefit + CTA (Trust Framework)
```
[Rating/Award/Number]. [Benefit statement]. [CTA].
```
Example: "Rated 4.9/5 by 10,000+ customers. Fast, reliable, affordable shipping. Shop now & save." (89 chars)

### Formula 5: Feature Stack + CTA (Features Framework)
```
[Feature 1], [Feature 2] & [Feature 3]. [CTA].
```
Example: "Free shipping, easy returns & 24/7 support. Everything you need in one place. Order now." (89 chars)

### Formula 6: Before/After + CTA (Transformation Framework)
```
Go from [current state] to [desired state]. [How/CTA].
```
Example: "Go from overwhelmed to organized in minutes. Try our project management tool free today." (89 chars)

### Formula 7: Risk Reversal + CTA (Guarantee Framework)
```
[Guarantee/Risk removal]. [Benefit]. [CTA].
```
Example: "30-day money-back guarantee. No risk, no hassle. See why 50K+ businesses switched to us." (89 chars)

### Formula 8: Question + Answer + CTA (Engagement Framework)
```
[Question]? [Answer with USP]. [CTA].
```
Example: "Need it fast? We offer same-day delivery on all orders over $50. Shop the collection now." (90 chars)

## USP Integration Rules

When the user provides USPs, integrate them into descriptions following these priorities:

1. **Lead with the strongest USP** in Description 1
2. **Stack 2-3 secondary USPs** in Description 2 using commas
3. **Use proof to back USPs** in Description 3 (numbers, ratings, years)
4. **Combine USP with offer** in Description 4

### USP Priority Matrix

| USP Type | Integration Method | Example |
|----------|-------------------|---------|
| Price | Lead with savings amount | "Save 40% vs competitors" |
| Speed | Specific timeframe | "Delivered in 24 hours" |
| Quality | Material/process detail | "Handcrafted Italian leather" |
| Guarantee | State the guarantee upfront | "100% satisfaction guaranteed" |
| Selection | Quantity emphasis | "Choose from 5,000+ styles" |
| Expertise | Years/credentials | "Board-certified specialists" |
| Technology | Name the tech advantage | "AI-powered recommendations" |
| Convenience | Remove friction | "No appointment needed" |

## CTA Placement Strategy

### Strong CTAs by Industry

| Industry | Top CTAs | Avoid |
|----------|----------|-------|
| Lead Gen (B2B) | "Get a Free Quote", "Book a Demo", "Talk to an Expert" | "Buy Now", "Shop" |
| E-commerce | "Shop Now", "Order Today", "Browse Collection" | "Learn More", "Contact Us" |
| Local Services | "Call Now", "Book Online", "Get Free Estimate" | "Shop", "Subscribe" |
| SaaS | "Start Free Trial", "See Plans", "Try Free for 14 Days" | "Call Now", "Visit" |
| Healthcare | "Book Appointment", "Find a Doctor", "Schedule Today" | "Buy", "Order" |
| Real Estate | "View Listings", "Schedule a Tour", "See Available Homes" | "Buy Now", "Order" |
| Education | "Enroll Now", "Apply Today", "Download Brochure" | "Shop", "Buy" |

### CTA Formatting Rules
- Always use an action verb (Get, Start, Book, Call, Try, Shop, Claim, Download)
- Add benefit after the verb when space allows: "Get Your Free Quote" > "Get a Quote"
- Urgency modifier when appropriate: "Book Now", "Start Today", "Claim Before Friday"
- End descriptions with a period after CTA for cleaner appearance in ads

## Character Optimization Techniques

When you're 5-10 characters over the 90-character limit:
1. Remove articles (a, an, the) — "Get the best deal" → "Get best deal"
2. Use ampersand — "and" → "&" (saves 2 chars)
3. Use numbers — "twenty" → "20" (saves 4 chars)
4. Use abbreviations — "approximately" → "~", "information" → "info"
5. Remove filler words — "that", "just", "really", "very"
6. Use shorter synonyms — "purchase" → "buy", "discover" → "find"
7. Combine phrases — "We offer free shipping" → "Free shipping included"
