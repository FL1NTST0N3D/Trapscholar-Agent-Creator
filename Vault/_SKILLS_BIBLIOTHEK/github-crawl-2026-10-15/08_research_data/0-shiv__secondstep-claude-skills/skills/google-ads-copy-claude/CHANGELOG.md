# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-03-15

### Added

- Main skill router (`SKILL.md`) with 10 `/copy` subcommands.
- Sub-skills for RSA generation, headline formulas, description writing, DKI helper, Ad Strength audit, competitor analysis, emotional triggers, CTA optimizer, A/B testing, and ad copy reports.
- 13 copywriting frameworks: AIDA, PAS, FAB, Before-After-Bridge, 4Cs, QUEST, USP-Driven, Social Proof, Urgency/Scarcity, Question-Based, Number/Stat, Comparison, Risk Reversal.
- Agent workflows: full RSA workflow, bulk ad generator, competitor-to-ad, copy audit agent.
- Python utilities: character counter, Ad Strength scorer, RSA CSV exporter.
- Output templates: RSA, audit report, A/B test plan, competitor analysis, sample RSA data.
- Reference docs: RSA best practices, Google Ads policies, industry benchmarks, PMax copy guide, extensions copy guide.
- `install.sh` and `uninstall.sh` scripts.
- `skill.json` manifest with full command and agent registry.
