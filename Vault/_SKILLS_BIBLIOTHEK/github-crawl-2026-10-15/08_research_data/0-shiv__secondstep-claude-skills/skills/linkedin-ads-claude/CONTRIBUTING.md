# Contributing to LinkedIn Ads Claude

Thanks for your interest in contributing!

## How to Contribute

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Test the skill in Claude Code
5. Submit a pull request

## Guidelines

- Keep SKILL.md files focused and under 500 lines
- Include real LinkedIn Ads benchmarks and best practices
- Test all commands before submitting
- Follow existing naming conventions (kebab-case directories)
- Reference LinkedIn Campaign Manager terminology correctly
- Add yourself to contributors in your PR

## Reporting Issues

Open an issue on GitHub with:
- Command that failed
- Expected behavior
- Actual behavior
- Any error messages

## Code of Conduct

Be respectful, constructive, and helpful. We're all here to make B2B advertising better.
