## Data Quality Notes
- Free sources have limitations: less data, lower accuracy, manual collection
- Paid tools provide estimates, not exact numbers — treat as directional
- Combine multiple sources for triangulation and higher confidence
- Date-stamp all data collection — competitive intelligence decays fast
