# Analysis Frameworks Reference

## 1. Porter's Five Forces
Analyze the competitive intensity and attractiveness of a market.

| Force | Questions to Answer |
|-------|-------------------|
| **Rivalry** | How many competitors? How aggressive? Price wars? |
| **Buyer Power** | How much leverage do customers have? Switching costs? |
| **Supplier Power** | How dependent on key suppliers/platforms? |
| **Threat of Substitutes** | What alternatives exist outside the category? |
| **Threat of New Entrants** | How hard is it to enter this market? Barriers? |

## 2. SWOT Analysis
Internal capabilities + external environment.

```
           Positive          Negative
Internal   STRENGTHS         WEAKNESSES
External   OPPORTUNITIES     THREATS
```

### Strategic Implications Matrix
- **SO**: Use strengths to capture opportunities
- **WO**: Address weaknesses to capture opportunities
- **ST**: Use strengths to defend against threats
- **WT**: Minimize weaknesses and avoid threats

## 3. Perceptual Positioning Map
Plot competitors on two dimensions that matter to buyers.

Common dimension pairs:
- Price vs Quality
- Ease of Use vs Power
- SMB vs Enterprise
- Point Solution vs Platform
- Specialized vs General

## 4. Value Chain Analysis
Compare how competitors create and deliver value:

```
Inbound -> Operations -> Outbound -> Marketing/Sales -> Service
```

## 5. Jobs-to-Be-Done (JTBD)
Understand what "job" buyers are hiring the product to do:
- **Functional job**: What task needs completing?
- **Emotional job**: How do they want to feel?
- **Social job**: How do they want to be perceived?

## 6. Blue Ocean Strategy Canvas
Plot value curves across key competitive factors:

```
| Factor | Competitor A | Competitor B | You | Industry Average |
|--------|-------------|-------------|-----|-----------------|
| Price | 8 | 5 | 6 | 6 |
| Features | 6 | 9 | 7 | 7 |
| Ease of Use | 4 | 3 | 8 | 5 |
```

Look for opportunities to eliminate, reduce, raise, or create factors.

## 7. Competitive Response Framework
Predict how competitors will respond to your moves:

| Response Type | When It Happens |
|--------------|----------------|
| **Ignore** | Move is too small or outside their focus |
| **Match** | Move threatens core business, easy to copy |
| **Counter** | Move threatens core business, they differentiate response |
| **Retreat** | Move makes their position untenable in that segment |
| **Escalate** | They respond with a bigger move (price war, feature race) |

## 10. Technology Maturity Model
Assess competitor operational sophistication:

| Level | Marketing | Engineering | Data |
|-------|-----------|-------------|------|
| **1 - Basic** | Spreadsheets, manual | Monolith, manual deploy | No analytics |
| **2 - Growing** | Basic CRM, email | CI/CD, some testing | GA, basic tracking |
| **3 - Scaling** | Marketing automation | Microservices, IaC | Data warehouse, BI |
| **4 - Mature** | Full martech stack | Platform engineering | ML/AI, real-time |
| **5 - Advanced** | AI-driven, predictive | Self-healing, edge | Predictive, embedded |
