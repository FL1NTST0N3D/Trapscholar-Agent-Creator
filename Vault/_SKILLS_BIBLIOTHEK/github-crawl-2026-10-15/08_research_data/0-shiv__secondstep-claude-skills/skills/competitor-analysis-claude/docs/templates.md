# Output Templates & Examples

## 1. Competitor Snapshot (Quick Reference)

```markdown
## [Competitor Name] — Snapshot
**Updated**: YYYY-MM-DD

| | |
|---|---|
| **Founded** | [Year] |
| **HQ** | [Location] |
| **Employees** | [Count] |
| **Funding** | [Total raised] |
| **Revenue** | [Estimate] |
| **Pricing** | [Starting at $X/mo] |
| **Category** | [Self-defined category] |
| **Threat Level** | Low / Medium / High |

**One-line summary**: [What they do, for whom, and how they position]
```

```markdown
|---|---|
| O1: [Market opportunity] | T1: [External threat] |

```

## 5. Sales Battlecard (One-Page)

```markdown
# Battlecard: Us vs [Competitor]
*For internal sales use only — Updated YYYY-MM-DD*

## 15-Second Pitch
"Unlike [Competitor] which [limitation], we [key differentiator] so you get [outcome]."

## Win Themes
1. [Theme] — [Proof point]
2. [Theme] — [Proof point]
3. [Theme] — [Proof point]

## When They Say... You Say...
| Objection | Response |
|---|---|
| "They're cheaper" | "[Response]" |
| "They have [feature]" | "[Response]" |
| "Everyone uses them" | "[Response]" |

## Landmines to Set
- "Ask them about [weakness area]"
- "Have them demo [problematic workflow]"

## You Win When | You Lose When
| Win | Lose |
|---|---|
| [Scenario] | [Scenario] |
```
