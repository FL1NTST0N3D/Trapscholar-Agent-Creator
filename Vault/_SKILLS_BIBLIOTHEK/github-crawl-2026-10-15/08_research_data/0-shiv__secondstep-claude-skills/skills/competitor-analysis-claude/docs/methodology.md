# Competitive Intelligence Methodology

## Overview
This skill uses a three-phase methodology for competitive intelligence: Research, Analysis, and Strategy. Each phase has distinct objectives, methods, and outputs.

## Phase 1: Research (CI Researcher Agent)

### Objective
Gather comprehensive, factual data about competitors from publicly available sources.

### Methods
1. **Primary Research**: Direct observation of competitor websites, products, pricing pages, and public communications
2. **Secondary Research**: Third-party data from review sites, analyst reports, news coverage, and industry databases
3. **Technical Research**: Technology detection through HTTP headers, page source analysis, and DNS records
4. **Social Research**: Social media presence, engagement patterns, employee activity on LinkedIn

### Data Quality Standards
- Every data point tagged with confidence level
- Sources documented with URL and access date
- Data freshness noted (some sources go stale quickly)
- Gaps explicitly flagged rather than filled with assumptions

## Phase 2: Analysis (CI Analyst Agent)

### Objective
Transform raw data into structured frameworks and derived insights.

### Frameworks
- **SWOT**: Internal strengths/weaknesses + external opportunities/threats
- **Positioning Maps**: 2x2 perceptual maps on buyer-relevant dimensions
- **Feature Matrices**: Feature-by-competitor comparison tables
- **Pricing Models**: Tier comparison, price-per-unit economics, TCO analysis
- **Content Gap Analysis**: Topic coverage, SERP overlap, authority comparison

### Quality Standards
- All derived metrics show calculation methodology
- Ranges used instead of false precision for estimates
- Assumptions stated explicitly
- Statistical significance noted where relevant

## Phase 3: Strategy (CI Strategist Agent)

### Objective
Convert analytical findings into prioritized, actionable recommendations.

### Decision Framework
Each recommendation evaluated on:
- **Impact**: Competitive advantage gained (High/Med/Low)
- **Feasibility**: Resource requirements and execution difficulty
- **Urgency**: Time sensitivity and competitive window
- **Risk**: Downside if the action fails or competitor responds

### Output Standards
- Recommendations tied to specific findings
- Actions assigned to functional owners
- Timelines specified
- Expected competitor responses anticipated

## Ethical Guidelines
- Use only publicly available information
- Do not attempt to access private systems or data
- Do not misrepresent identity to obtain information
- Respect terms of service and robots.txt
- Distinguish between observation and inference
