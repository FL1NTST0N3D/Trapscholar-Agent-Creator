# Contributing to Competitor Analysis Claude

Thanks for your interest in contributing!

## How to Contribute

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Test the skill in Claude Code
5. Submit a pull request

## Guidelines

- Keep CLAUDE.md files focused and under 500 lines
- Include real competitive intelligence frameworks and methodologies
- Test all commands before submitting
- Follow existing naming conventions (kebab-case directories)
- All data points must include confidence levels (Confirmed / Estimated / Inferred)
- Use only publicly available, ethical data sources
- Add yourself to contributors in your PR

## Skill File Structure

Each sub-skill CLAUDE.md should follow this structure:

1. **Purpose** — What the skill does and why it matters
2. **When to Use** — Specific scenarios and use cases
3. **Framework** — Step-by-step analysis methodology
4. **Output Template** — Structured markdown template for results
5. **Best Practices** — Tips and guidelines for quality analysis

## Reporting Issues

Open an issue on GitHub with:
- Command that failed
- Expected behavior
- Actual behavior
- Any error messages

## Code of Conduct

Be respectful, constructive, and helpful. We are all here to make competitive intelligence more accessible and systematic.
